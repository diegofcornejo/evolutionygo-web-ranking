# Season Share Card Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the stale "Welcome Season 4" share image with a 1200×630 PNG card generated at build time from `PUBLIC_DEFAULT_SEASON`, and drop "Yu-Gi-Oh" from the share text.

**Architecture:** A prerendered Astro endpoint (`/og/season-<N>.png`) builds the card with Satori (layout + text → SVG paths) and sharp (SVG → PNG). A tiny helper module gives the URL to `SEO.astro`, which uses it as the default image. Nothing new runs in the Vercel function.

**Tech Stack:** Astro (SSR, Vercel adapter), Satori 0.x, sharp 0.35 (already in the tree via Astro), `@fontsource/plus-jakarta-sans` (static `.woff` files), Vitest.

**Spec:** `docs/superpowers/specs/2026-11-22-og-image-design.md`

## Global Constraints

- Card size 1200×630, PNG, under 300 KB.
- Card never says "Yu-Gi-Oh"; it says "YGO". Card copy, exactly: `SEASON {N}`, `YGO duels in your browser`, `EvoDuel · EDOPro · Koishi · YGO Mobile`, `evolutionygo.com`.
- Season comes from `import.meta.env.PUBLIC_DEFAULT_SEASON` only.
- Card URL: `/og/season-{N}.png`.
- Background `public/profile/banner-1920.webp` (cover, darkened toward the left); logo `public/logo.svg` rasterized to PNG before embedding. Satori gets no WebP and no WOFF2.
- `satori`, `sharp`, `@fontsource/plus-jakarta-sans` go in `devDependencies` and must not end up in the Vercel function.
- Keep `public/banners/banner1.webp` (tournament mock data uses it). Leave every SEO `keywords` list unchanged.
- Commit messages: conventional subject only, no body, no trailers.

## Review Focus

1. `PUBLIC_DEFAULT_SEASON` unset at build → the build must fail with a clear message, not publish `/og/season-undefined.png`. (Task 1 test.)
2. Satori or sharp bundled into the serverless function → the deploy would break at runtime like the adapter incident. (Task 1 build check.)
3. A two-digit season (`10`) must still render inside 1200×630 under 300 KB. (Task 1 test.)
4. Pages that pass their own image (duelist profile, 404) must keep it and must not claim `og:image:type` `image/png`. (Task 2 test.)
5. A PNG over 300 KB that WhatsApp may skip. (Task 1 test.)

- [ ] **Step 2: Write the failing tests**

```ts
import { describe, it, expect, vi, afterEach } from 'vitest';
import sharp from 'sharp';
import { seasonCardPath } from '../../src/utils/ogImage';

describe('season share card', () => {
  afterEach(() => vi.unstubAllEnvs());

  it('builds the card URL from the season', () => {
    expect(seasonCardPath('7')).toBe('/og/season-7.png');
  });

  it('prerenders only the current season', async () => {
    vi.stubEnv('PUBLIC_DEFAULT_SEASON', '7');
    const { getStaticPaths, prerender } = await import('../../src/pages/og/season-[season].png');
    expect(prerender).toBe(true);
    expect(getStaticPaths()).toEqual([{ params: { season: '7' } }]);
  });

  it('fails the build when PUBLIC_DEFAULT_SEASON is missing', async () => {
    vi.stubEnv('PUBLIC_DEFAULT_SEASON', '');
    const { getStaticPaths } = await import('../../src/pages/og/season-[season].png');
    expect(() => getStaticPaths()).toThrow('PUBLIC_DEFAULT_SEASON');
  });

  it.each(['7', '10'])('serves a 1200x630 PNG under 300 KB for season %s', async (season) => {
    const { GET } = await import('../../src/pages/og/season-[season].png');
    const response = await GET({ params: { season } } as any);
    expect(response.headers.get('Content-Type')).toBe('image/png');
    const bytes = Buffer.from(await response.arrayBuffer());
    const meta = await sharp(bytes).metadata();
    expect(meta.format).toBe('png');
    expect([meta.width, meta.height]).toEqual([1200, 630]);
    expect(bytes.length).toBeLessThan(300_000);
  }, 20_000);
});
```

`getStaticPaths` must read the env at call time (not at module load) so the stubs above apply.

Keep text away from the outer ~60 px; some apps crop the edges.

- Endpoint: `getStaticPaths` throws `Error('PUBLIC_DEFAULT_SEASON is not set')` when the env is empty; `GET` returns `new Response(png, { headers: { 'Content-Type': 'image/png' } })`.
